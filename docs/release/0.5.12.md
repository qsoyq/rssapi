# rssapi 0.5.12

## Changes

- Bilibili、Instagram、Telegram 媒体链接改为稳定 RSSAPI 地址，访问时重新解析上游并返回 `302`。
- 新增 `RSS_PUBLIC_SCHEME` 配置，默认使用 `https`；Feed 和媒体 URL 使用入站 `Host` 并保留端口。
- 移除本次未纳入发布范围的 Douyin/TikTok 媒体改造，保留原有 endpoint 行为。

## Validation

- `pre-commit run --files ...`
- `uv run ruff check .`
- `uv run ruff format --check .`
- `uv run pytest tests/`
- `uv build`

## Risk and Rollback

302 目标仍由客户端直接访问，部分上游可能要求 Cookie、Referer 或触发风控。若发布后需要回滚，在未创建发布物前回滚版本提交即可；已发布的 GitHub Release 保持不可变，应发布修复版本。
