# rssapi 0.5.5

Release boundary: `0.5.4..0.5.5`

## Changes

- TikTok v2 now requires a Cookie supplied through either `X-TikTok-Cookie` or the `cookies` query parameter. Requests without one fail fast with HTTP 400 instead of starting a browser session that may trigger TikTok verification ([#46](https://github.com/qsoyq/rssapi/pull/46)).
- Cookie query input is enabled by default and, when enabled, supports remote debugging clients. Set `RSS_TIKTOK_COOKIE_QUERY_ENABLED=false` to disable query input; prefer `X-TikTok-Cookie` to keep Cookies out of URLs and access logs.

No data migration is required.

## Known risks

- TikTok relies on undocumented web APIs and may still return an interactive verification challenge when a supplied Cookie has expired or is otherwise rejected.
- Cookie query values may appear in client or server access logs. Prefer `X-TikTok-Cookie` outside short-lived debugging.

## Rollback plan

- Before publication: revert the version bump and do not publish `0.5.5`.
- After publication: keep the public tag and Release immutable, revert or fix the affected change, and publish a corrective patch release.
