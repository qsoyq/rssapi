# rssapi 0.5.3

Release boundary: `0.5.2..0.5.3`

## Changes

- Instagram post feeds now return HTTP 401 when Instagram returns an anonymous soft-login payload (`status=ok` but no profile data), rather than returning a successful feed with no items ([#41](https://github.com/qsoyq/rssapi/pull/41)).

No configuration migration is required.

## Known risks

- Instagram relies on an undocumented upstream web API and may change its login or response behavior without notice.

## Rollback plan

- Before publication: revert the version bump and do not publish `0.5.3`.
- After publication: keep the public tag and Release immutable, revert or fix the affected change, and publish a corrective patch release.
