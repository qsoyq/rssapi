# rssapi 0.5.25

## Summary

- 修复 Twitter 将推文配图误用为作者头像的问题。
- 修复 YouTube 将视频封面误用为频道头像的问题。
- 修复抖音用户订阅、GoFans 和 Loon 将条目图片或应用图标混入作者头像的问题。
- 修复通用 JSON Feed 中间件从首条文章推断订阅作者、覆盖已有订阅图标的问题。
- 修复 Telegram 多频道聚合被首个频道身份覆盖的问题。

## Validation

- `uv run ruff check rssapi tests`
- `uv run ruff format --check rssapi tests`
- `uv run pytest -q`（436 passed, 54 deselected）
- `uv build`

## Risk and Rollback

- 风险：依赖历史上将 App/插件图标当作作者头像的客户端可能出现展示变化。
- 回滚：在发布 tag 前回滚本版本 bump 与修复提交；不要发布 `0.5.25` tag。
