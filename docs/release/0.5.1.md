# rssapi 0.5.1

Release boundary: `0.5.0..0.5.1`

## Changes

- Instagram JSON Feed posts now render images, videos, and carousel media before the non-media post body, with captions and post metadata collapsed behind the native `查看正文` control ([#37](https://github.com/qsoyq/rssapi/pull/37)).
- Added the 0.5.0 verification record and follow-up release documentation ([#36](https://github.com/qsoyq/rssapi/pull/36)).

No configuration migration is required.

## Validation

- `uv run pre-commit run --files pyproject.toml uv.lock docs/release/0.5.1.md`: passed, including the `uv-lock` and Python 3.10–3.14 tox startup checks.
- `uv lock --check`: passed.
- `uv run ruff check .`: passed.
- `uv run ruff format --check .`: passed; 135 files were already formatted.
- `uv run pytest -q`: 180 passed and 26 skipped; two unrelated external failures remained, one from changed geosite data and one from an NGA upstream 504 response.
- `uv build`: built `dist/rssapi-0.5.1.tar.gz` and `dist/rssapi-0.5.1-py3-none-any.whl`.
- Wheel and sdist metadata both report version `0.5.1` and include `rssapi/applications/instagram/utils.py`.

## Known risks

- Some RSS clients may sanitize or render HTML5 `<details>` content without interactive collapsing.
- Instagram relies on an undocumented upstream web API and expiring CDN URLs.

## Rollback plan

- Before publication: revert the version bump and do not publish `0.5.1`.
- After publication: keep the public tag and Release immutable, revert or fix the affected change, and publish a corrective patch release.
